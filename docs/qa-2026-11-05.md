## Verification limits

Native browser automation stopped before navigation because it could not identify the current URL confidently enough to enforce policy. The reviewer then inspected local screenshot files supplied by the primary agent. Real webcam/eye-tracker precision, camera recovery, PHP browsing, keyboard behavior, screen readers and long sessions are outside this screenshot review.
